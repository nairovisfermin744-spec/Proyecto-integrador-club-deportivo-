# Plan de pruebas manuales

Las pruebas siguientes deben ejecutarse en Visual Studio con MySQL configurado. Completar el resultado observado antes de entregar.

| N.º | Prueba | Resultado esperado | Resultado observado |
|---|---|---|---|
| 1 | Ingresar con admin/admin123 | Abre el menú principal | Pendiente |
| 2 | Ingresar con clave incorrecta | Muestra mensaje y no abre el menú | Pendiente |
| 3 | Registrar socio con documento, nombre y apellido | Guarda el socio en la base | Pendiente |
| 4 | Registrar otro socio con el mismo documento | Informa que el documento ya existe | Pendiente |
| 5 | Buscar socio para cobrar cuota | Muestra los datos del socio | Pendiente |
| 6 | Registrar pago con monto positivo | Guarda pago y actualiza vencimiento | Pendiente |
| 7 | Consultar vencimientos | Lista socios con cuota vencida hasta la fecha elegida | Pendiente |
| 8 | Ejecutar sin MySQL disponible | Muestra un mensaje de error entendible | Pendiente |

No marcar estas pruebas como aprobadas hasta ejecutarlas realmente.
